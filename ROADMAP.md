# Mona's Bookmark Manager Roadmap

A focused plan for improving bookmark safety and everyday usability.

| Area | Item | Type | Priority |
| --- | --- | --- | --- |
| Features | Import and export bookmarks | 🚀 | P1 |
| Features | Search and filter bookmarks | 🚀 | P1 |
| Features | Edit a saved bookmark | 🚀 | P2 |
| Features | Organize bookmarks with tags | 🚀 | P2 |
| Bugs & risks | Browser storage loss | 🐞 | P1 |
| Bugs & risks | Dependency audit advisories | 🐞 | P1 |

## 🚀 Planned features

- 🔁 Import and export bookmarks — Add portable backups to reduce the risk of losing data stored in the browser. [P1]
- 🔎 Search and filter bookmarks — Make saved links easier to find as the collection grows. [P1]
- ✏️ Edit a saved bookmark — Let users update a bookmark without deleting and re-adding it. [P2]
- 🏷️ Organize bookmarks with tags — Add lightweight labels to group and filter saved links. [P2]

## 🐞 Known bugs & risks

- 💾 Browser storage loss — Bookmarks can be lost if browser storage is cleared; import/export backups are a planned mitigation. [P1]
- 🐞 Dependency audit advisories — Investigate advisory reports and determine whether safe dependency updates are needed. [P1]
